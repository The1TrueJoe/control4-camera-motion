NVR Camera Motion Sensors

Exposes each camera channel of an ONVIF NVR/DVR as a standard Control4 contact (motion) sensor, driven by the NVR's own motion detection. A Homebridge plugin can then read these sensors by name and forward them to HomeKit Secure Video — no vendor code in the plugin.

Setup

  1. Set DVR Address, HTTP Port (default 80), Username and Password to an NVR account with an ONVIF/operator role.
  2. Set Camera Channel Count to the number of channels (1–8).
  3. Give each Camera N Name the camera's name, and rename the matching sensor sub-device in the project tree to the same name (the plugin matches by device name).
  4. Run the Test Connection action; Connection Status should read OK: ONVIF events available.

How it works

The driver opens an ONVIF PullPoint subscription on the NVR and long-polls PullMessages. Each tns1:VideoSource/MotionAlarm notification carries a channel token and a true/false state; the driver sets that channel's contact sensor open on motion and closed again after the Motion Hold window.

Channels

This driver ships with eight contact proxies. Channels above Camera Channel Count are left inert — hide or ignore them in Composer. To support more than eight channels, add matching <proxy> / <connection> pairs in driver.xml and rebuild.
